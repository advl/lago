# @aztlan/lago-react

Stories for React components drawn by OpenTUI, tested on every run.

`render`, `composeStories`, `setProjectAnnotations` and `waitFor` for tests, the story types `Meta`, `StoryObj`, `Decorator`, `Loader`, `Preview` and `GlobalTypes`, a story's `globals` and the `globals` its context gives, and from `@aztlan/lago-react/vitest` the plugin `testStories`, which draws every story at each viewport, inside the project's preview when one is named, and in each mode it is given, and compares it with its golden; a mode's picture keeps a golden only where it differs from the base's, and the run ends with the matrix totals.

See [the guide](../../docs/guide.md).
