# @aztlan/lago-react

Stories for React components drawn by OpenTUI, tested on every run.

`render`, `composeStories`, `setProjectAnnotations` and `waitFor` for tests, the story types `Meta`, `StoryObj`, `Decorator`, `Loader` and `Preview`, and from `@aztlan/lago-react/vitest` the plugin `testStories`, which draws every story at each viewport, inside the project's preview when one is named, and compares it with its golden.

See [the guide](../../docs/guide.md).
