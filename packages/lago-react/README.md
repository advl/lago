# @aztlan/lago-react

Stories for React components drawn by OpenTUI, tested on every run.

`render`, `composeStories` and `waitFor` for tests, the story types `Meta`, `StoryObj`, `Decorator` and `Loader`, and from `@aztlan/lago-react/vitest` the plugin `testStories`, which draws every story at each viewport and compares it with its golden.

See [the guide](../../docs/guide.md).
