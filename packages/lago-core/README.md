# @aztlan/lago-core

What a terminal screen shows, and its golden, for any renderer Lago checks.

A `Screenshot` is every run of text a screen shows with its colours and attributes, and a golden is that screenshot written as text: the picture, then one line per run. Neither names a renderer. `@aztlan/lago-react` reads OpenTUI's screen into a screenshot and keeps its goldens with what this package exports; a project imports from there.
