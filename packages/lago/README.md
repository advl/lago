# @aztlan/lago

A gallery of a project's stories, in a terminal.

`lago [project]` opens the gallery: the project's own vitest draws each story at each viewport, and a stories file is drawn again when it is saved. The gallery draws itself in the chrome the project's configuration names: `terminal`, the terminal's own colours, unless it names `light`, `dark` or a set of tokens of its own. This package also carries the skill that adopts Lago in a project, in `skills/adopt-lago`.

See [the guide](../../docs/guide.md).
