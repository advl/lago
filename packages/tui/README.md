# @aztlan/tui

Terminal components for applications drawn by OpenTUI.

The pane, its header, the scrolled list with pinned group headings, the key bar and the help fed by the keymap, notices, loading lines and empty states; `Keys`, `createKeymap`, `useCommands` and `useListScroll`; and the functions that fit text to the cells it is given.

See [the guide](../../docs/guide.md).
