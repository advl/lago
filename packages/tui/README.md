# @aztlan/tui

Terminal components for applications drawn by OpenTUI.

The pane, its header, the scrolled list with pinned group headings, the key bar and the help fed by the keymap, notices, loading lines and empty states; `Keys`, `createKeymap`, `useCommands` and `useListScroll`; the functions that fit text to the cells it is given; and the `tokens` every component draws with, read through `useTokens`, which a `TokensProvider` sets for everything under it.

See [the guide](../../docs/guide.md).
